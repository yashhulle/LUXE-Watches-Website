# ⌚ LUXE Watches Website

A modern, responsive luxury watch website built using **HTML, CSS, and JavaScript** with smooth animations and premium UI design.

---

## 🚀 Features

* 🔝 Sticky transparent header with navigation
* 🎥 Fullscreen hero section with video background
* 🖼️ Parallax scrolling effect
* 🧾 Brand story section with animated statistics
* 🤝 Featured partners with hover effects
* ⌚ Watch showcase slider (manual + auto)
* 📰 Latest news/blog section
* 📱 Fully responsive design (Mobile → Desktop)
* ⚡ Smooth animations using GSAP
* 🔍 Clean and SEO-friendly structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, Grid, Media Queries)
* JavaScript (Vanilla JS)
* GSAP (Animations & ScrollTrigger)

---

## 📱 Responsive Design

This website is fully responsive and optimized for:

* Mobile (320px+)
* Tablet (768px+)
* Laptop (1024px+)
* Desktop (1440px+)

---

## ⚡ Performance Optimizations

* Optimized image sizing
* Lazy loading support (recommended)
* Efficient DOM handling
* Smooth scroll and animation triggers
* Lightweight and fast loading
